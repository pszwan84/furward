# 绒途 Furward · 机器导盲犬项目整合版

这个文件夹把品牌首页、中文内容后台、3D 城市、人物与机器狗动画、独立路线演示服务放在同一个工程中。打开首页后可以进入城市体验，观看机器狗带领人物沿路线行走，并操作暂停、遇障、清障、继续和结束。

当前网站中的行走是**独立仿真演示**。原来的机器狗后端与 T1 桥接仍保留在 `robot/`，需要另行配置和验证，不会被网站启动脚本自动连接。

## 先打开项目

本机需要 **Node.js 24 或更新版本**、**Python 3.10 或更新版本**。第一次启动需要联网下载依赖。

在 Mac 上，双击本目录的 **`启动绒途.command`**。它会打开终端，准备依赖并启动整套网站。看到“绒途已启动”后访问：

| 用途 | 本地地址 |
| --- | --- |
| 品牌首页 | [http://localhost:3000/](http://localhost:3000/) |
| 城市体验 | [http://localhost:3000/experience](http://localhost:3000/experience) |
| 中文内容后台 | [http://localhost:3000/admin](http://localhost:3000/admin) |

也可以在终端执行：

```sh
cd "/Users/xuchengming/Documents/ChatGPT/导盲犬机器狗项目/furward-integrated"
npm start
```

启动窗口需要保持打开。停止时在该窗口按 `Ctrl+C`。脚本会检查是否已经运行，避免重复启动；若其他程序占用了端口，会显示具体端口。默认使用 `3000`、`3001`、`8100` 三个端口，日常浏览只需打开 `3000`。

同一 Wi-Fi 下的其他设备，请使用启动窗口打印的“同一 Wi-Fi”地址。当前电脑地址是 [http://172.168.23.102:3000/experience](http://172.168.23.102:3000/experience)，已由本机及独立 Linux 虚拟客户端经该网卡 IP 验证 HTTP、WS、双访客、暂停重连和完整 150 米路线（125.7 秒）；换网络后地址可能变化。`localhost` 只指向当前设备。手机公网体验已由用户反馈显示、操作和播报正常。虚拟客户端测试不涵盖实体手机经 Wi-Fi 路由器的链路，详细范围见[自主网络验收记录](docs/verification/lan-isolated-client.json)。

## 如何体验一条完整路线

1. 打开“城市体验”，等待城市和角色加载完成，点击开始。
2. 路线从“西街口”到“街心花园”，共 **150 米、4 步**，按 **1.2 米/秒**前进。
3. 行进到 **32 米**时自动遇障并停下。先清除障碍，再点击继续；清障本身不会让角色自动出发。
4. 可以随时暂停、继续或结束。结束会保留停下的位置；重新体验才返回起点。
5. 支持文字指令，例如“带我去街心花园”“停一下”“继续”“结束导航”。没有接入麦克风录音识别；浏览器播报不可用时仍可阅读文字指引。

人物和机器狗保留原模型外观，加入站立、行走、左右转向和停步动画。角色走路由骨骼驱动，整体位置由路线控制。贴地、转向、完整路线以及结束后重播已完成浏览器回归，生产构建也已通过。

人物行走已加入脚掌滚动，并调整到约每分钟 131 步；提供可继续编辑的 Blender 动画工程。画面最多渲染约 60 帧/秒，隐藏页面时停止渲染，回来后恢复当前路线状态；实际流畅度仍取决于设备性能。

每位访客拥有自己的会话，一个人暂停或结束不会影响其他人。刷新同一页面可以恢复仍有效的会话；连接正常关闭后有 10 秒重连宽限；突然断网但没有关闭通知时，通过心跳识别失联并暂停，通常在最后一次心跳后约 25 秒内停下。已暂停的会话重连后需主动继续。会话 30 分钟无活动后过期，服务重启后也需要重新体验。

## 管理员与资料保存

首次启动会生成本地管理员配置，登录信息保存在 **`.runtime/管理员登录信息.txt`**。这是私密文件，请在本机查看，不要放进公开文档、截图或源码包。已有配置时启动脚本不会重新生成密码。

内容后台用于修改首页文字和图片。已保存内容与上传图片在 `web/data/`，管理员配置在 `web/.env.production`；这些属于运行资料，不包含在公开源码包里。

在工程根目录运行：

```sh
npm run export
```

会在 `outputs/` 生成 `绒途Furward-完整整合源码-日期时间.zip`，包含网站、城市与动画资产、演示服务、原机器人代码和说明文件，排除密码、环境文件、数据库、上传资料、依赖目录和缓存。**源码包不是网站运行数据的完整备份**，需要迁移后台已上传图片时应另外备份运行资料。

## 三个人如何继续分工

| 目录 | 放什么 | 修改时注意 |
| --- | --- | --- |
| `web/` | 首页、中文后台、城市体验前端、公开模型资产 | 首页与城市体验可以分开维护；不要用默认内容覆盖后台已保存内容 |
| `demo-service/` | 每位访客独立的路线仿真与实时状态 | 保持与机器人控制隔离，接口见协议文档 |
| `shared/route.json` | 前后端共用的路线、步骤、速度与模型地址 | 调整路线时前后端共同使用这一份数据 |
| `robot/backend/`、`robot/bridge/` | 原手机交互、调试接口、T1 桥接 | 另行安装和运行；真机验证独立进行 |
| `source-assets/city/`、`source-assets/characters/` | 原城市工程、碰撞资料、可编辑人物与狗的 Blender 动画工程 | 作为建模与溯源输入保留；动画工程附两秒行走预览 |
| `scripts/`、`deploy/` | 启动、导出、模型处理、验收与部署脚本 | 根目录 `npm start` 是统一入口 |
| `docs/` | 接口、动画方法、整合说明与验收记录 | 新增能力后同步更新 |

建议每人负责独立目录，同一批未提交文件不要同时用多个工具修改。

## 验证与更多说明

本次已记录：主页/CMS/管理员 **47 项**、独立部署 **9 组**、原后端 **252 项**、桥接 **27 项**、独立演示服务 **30 项**检查通过。各项口径不同，不合并为一个总数。

本地真实统一入口验收已跑完 150 米路线，实际耗时 **125.6 秒**；双访客隔离、32 米遇障、清障后手动继续、文字结束、刷新与重连均通过。最终步态及帧率更新后，本地浏览器再次到达 150 米；生产容器经 SSH 通道验收耗时 **126.3 秒**。放行入口后的真实公网直连验收耗时 **126.4 秒**，未跳过 TLS 验证；原机器人调试与桥接接口未对外开放。用户已反馈手机公网体验的显示、操作和播报均正常。补充的独立 Linux 客户端通过电脑网卡地址完成 125.7 秒完整路线验收。后台登录与只读检查通过；这些结果不代表实体机器狗已经完成现场测试。
